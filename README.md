## The joke

> HR told me to bring my whole self to work, so I brought my burnout too — it got promoted first.

HR asked for the whole self. The burnout showed up, outworked everyone, and got the promotion. Classic office meritocracy.

## Run

```bash
python3 main.py
```

This writes the joke to `output/entry.txt` (or `/output/entry.txt` when writable), verifies the round-trip, and prints the joke with its character count.
